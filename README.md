# AdSpark AI — استوديو توليد الفيديوهات الإعلانية بالذكاء الاصطناعي

## هيكل الملفات:
- `index.html`: واجهة المنصة الرئيسية ونوافذ الاشتراك ولوحة المشرف.
- `styles.css`: التصميم الداكن العصري المتجاوب مع الهواتف والحواسيب.
- `app.js`: منطق تسجيل الدخول عبر Gmail، إدارة النقاط، لوحة المشرف، وتوليد الفيديو الحقيقي بالصوت والصورة.

## طريقة التشغيل في VS Code:
1. فك الضغط عن الملف وافتح مجلد `AdSpark-AI` داخل **VS Code**.
2. افتح ملف `index.html` وشغله عبر إضافة **Live Server** أو افتحه مباشرة في المتصفح.
